# أوسكار - نظام إدارة المبيعات PWA

تطبيق ويب قابل للتثبيت على الجوال والكمبيوتر، مخصص للكاشير والمخزون والعملاء والموردين والحسابات والفواتير والصلاحيات.

## التعديلات المنفذة
- حذف قسم التصنيع بالكامل من القائمة والملفات.
- حذف زر التثبيت من الواجهة. التثبيت يتم من قائمة المتصفح: إضافة إلى الشاشة الرئيسية / Install app.
- حذف بطاقة وكلمة متصل، والإبقاء على نقطة حالة الشبكة فقط.
- تغيير الاسم الافتراضي إلى: أوسكار، ويمكن تغييره من صفحة الإعدادات.
- إضافة صفحة تسجيل دخول موحدة: مفتاح الشركة، اسم المستخدم، كلمة المرور.
- إضافة قسم الموظفين والصلاحيات، مع إخفاء القوائم حسب الصلاحية.
- ضغط المقاسات والبطاقات للجوال، مع تحسين توافق الجوال/التابلت/اللابتوب.
- تحويل ملصقات القائمة السفلية والجانبية إلى أيقونات SVG داخلية.

## ملاحظات أمنية مهمة
تم تنفيذ تسجيل دخول محلي/سحابي مع SHA-256 + Salt في الواجهة. للإطلاق التجاري الحقيقي، يفضل ربط تسجيل الدخول بـ Firebase Auth + Custom Claims أو Cloud Functions حتى تكون قواعد Firestore قادرة على التحقق من الصلاحيات من `request.auth.token`، وليس من بيانات جلسة محفوظة في المتصفح فقط.
